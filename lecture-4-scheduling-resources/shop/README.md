# shop 0.2.0

Собственный chart из Лабы 3 с дополнениями Лабы 4: batch, переключаемое разнесение API, PriorityClass, PDB, ресурсы из krr и мониторинг SLA.

Команды, обоснования и результаты экспериментов: [README лабораторной](../README.md), [REPORT](../REPORT.md).

`values.yaml` — рабочий финальный профиль. Файлы `../experiments/*.yaml` передаются дополнительными `-f` только для соответствующего эксперимента. Скрипт upgrade каждый раз начинает с финальных defaults, а не `--reuse-values`: возврат без экспериментального файла восстанавливает рабочий профиль.
